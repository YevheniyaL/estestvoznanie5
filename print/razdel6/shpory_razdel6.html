§53. Экосистема — «совместное» хозяйство

Естествознание, ч. 2 · стр. 112–114

Главная мысль: живое и неживое в экосистеме — одно хозяйство; без любого звена оно ломается. ✏️

Слова (§53)

  • Экосистема — организмы + неживая природа, обмен энергией
  • Производители — растения, делают пищу
  • Потребители — животные, едят готовое
  • Разрушители — черви, грибы, бактерии

Факты

  • слово ввёл А. Тенсли в 1935 г.
  • основа любой экосистемы — свет Солнца
  • неживое: воздух, вода, почва, горные породы
  • «вредные» — только для человека; в природе важны все

Цепочка: Солнце → производители → потребители → разрушители → почва → снова растениям.

§54. Виды экосистем

Естествознание, ч. 2 · стр. 115–119

Главная мысль: три признака — откуда взялась, какого размера, откуда энергия. ✏️

Слова (§54)

  • Естественная — без человека (лес, болото)
  • Искусственная — создал человек (поле, сад, город)
  • Микро → мезо → макро → глобальная
  • поляна → лесной массив → степь, море → Земля

По источнику энергии

  • Солнце — океан, высокогорный лес
  • Солнце + природа — берега Сырдарьи
  • Солнце + человек — поля, огороды
  • топливо — города (энергии ×80 к нужной телу)

Цепочка: природа раскладывает энергию «по разным карманам», человек — в один-два вида.

§57. Четыре царства живой природы

Слова (§57)

  • Царство — большая группа, похожая по строению и питанию
  • Бактериология — наука о бактериях
  • Аристотель → Линней (XVIII в., 3 царства) → 4 царства

  • бактерии — одна клетка, нет ядра

§58. Одноклеточные и многоклеточные

Естествознание, ч. 2 · стр. 132–135

Главная мысль: клетка одноклеточного живёт сама, клетка многоклеточного — только в команде. ✏️

Слова (§58)

  • Клетка: мембрана · цитоплазма · ядро
  • Одноклеточные — тело из одной клетки
  • Многоклеточные — много клеток → ткани → органы
  • амёба, хламидомонада · человек, дуб

Цифры

  • одноклеточные: 0,1–0,5 мм, > 60 000 видов животных
  • появились > 2 млрд / многоклеточные ≈ 700 млн лет назад
  • многоклеточные: 0,04 мм (коловратка) — 160 м (секвойя)
  • насекомых > 1 млн видов; теория — Мечников

Цепочка: яйцеклетка → делится, клетки не расходятся → ткани → органы → организм.
